# ML-лабораторія для відкритих даних

Навчальний інтерактивний веб-застосунок на Streamlit для аналізу та машинного навчання на відкритих даних (data.gov.ua) без необхідності редагування вихідного коду. Створено в рамках курсу «Python для машинного навчання» (КАІ).

---

## 🚀 Основні можливості

1. **Завантаження та попередній огляд відкритих даних**:
   - Підтримка форматів CSV (з вибором кодування `utf-8`, `windows-1251` та автовизначенням/ручним вибором роздільника) та XLSX.
   - Відображення розмірності, типів даних, пропущених значень та описової статистики `describe()`.
   - Автоматична ідентифікація типів стовпців (числові, категоріальні, дати/часові мітки).

2. **Підготовка даних без витоку (Data Leakage Free)**:
   - Автоматична побудова `scikit-learn` конвеєрів (`Pipeline` + `ColumnTransformer`).
   - Навчання трансформерів імпутації, масштабування та кодування строго на тренувальній вибірці.
   - Попередження та захист від високої кардинальності категоріальних ознак (> 50 унікальних значень).

3. **Задачі машинного навчання**:
   - **Класифікація**: `LogisticRegression`, `RandomForestClassifier` (оцінка дисбалансу, матриця невідповідностей, Classification Report, F1-macro, PR-метрики).
   - **Регресія**: `Ridge`, `RandomForestRegressor` (MAE, RMSE, R², графіки «факт vs прогноз», залишки).
   - **Виявлення аномалій**: `IsolationForest`, `LocalOutlierFactor` (ранжування топ-N аномалій, PCA-2D проекція, z-score аналіз відхилень).

4. **Експорт результатів**:
   - Вивантаження збагачених датасетів із прогнозами та оцінками аномалій у форматі CSV.
   - Збереження навчених моделей (`joblib`).

## 📁 Структура проєкту

```text
├── app.py                 # Точка входу Streamlit, головна навігація
├── src/
│   ├── __init__.py
│   ├── data_loader.py     # Завантаження, виявлення роздільників/кодувань, типізація
│   ├── preprocessing.py   # Конвеєри ColumnTransformer та Pipeline без витоку даних
│   ├── validation.py      # Валідація даних та інтерфейсні повідомлення українською
│   ├── classification.py  # Навчання, балансування та метрики класифікації
│   ├── regression.py      # Моделі регресії та метрики
│   ├── anomaly.py         # Виявлення аномалій та z-score пояснення
│   ├── plots.py           # Побудова візуалізацій (matplotlib / seaborn)
│   └── export.py          # Експорт прогнозів та збереження моделей
├── tests/                 # Unit-тести на синтетичних та "брудних" даних
├── data/                  # Демонстраційні датасети
├── requirements.txt       # Фіксовані залежності проєкту
├── .gitignore             # Виключення системних файлів та артефактів
└── README.md              # Документація проєкту
```

## 🛠️ Встановлення та запуск

### 1. Клонування репозиторію та створення віртуального середовища

```bash
# Створення віртуального оточення
python -m venv .venv

# Активація віртуального оточення:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (cmd):
.venv\Scripts\activate.bat
# Linux / macOS:
source .venv/bin/activate
```

### 2. Встановлення залежностей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Запуск застосунку

```bash
streamlit run app.py
```

Після запуску відкрийте браузер за адресою [http://localhost:8501](http://localhost:8501).

## 📋 Вимоги до структури файлів

- **Формати**: `.csv`, `.tsv`, `.xlsx`.
- **Кодування**: `utf-8` (за замовчуванням) або `windows-1251` (поширене в українських державних реєстрах).
- **Роздільники CSV**: кома (`,`), крапка з комою (`;`), табуляція (`\t`).
- **Мінімальний розмір вибірки**: від 30 рядків після видалення пропусків у цільовій змінній.
