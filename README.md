# ML-лабораторія для відкритих даних

**Інтерактивний навчальний веб-застосунок на базі Streamlit для аналізу та моделювання відкритих даних (data.gov.ua) без необхідності редагування коду.**

Створено в рамках курсу «Python для машинного навчання» (КАІ).

---

## 🎯 Цільова аудиторія та призначення

Застосунок розроблено для аналітиків територіальних громад, студентів та дослідників. Користувач може завантажити будь-яку таблицю відкритих даних (наприклад, реєстри комунального майна, витрат бюджету, запитів чи нерухомості) і без жодного рядка коду вирішити одну з трьох ключових задач машинного навчання:
1. **Класифікація** (прогнозування категорій або статусів).
2. **Регресія** (прогнозування неперервних числових показників).
3. **Виявлення аномалій** (пошук нетипових витрат, помилок чи підозрілих записів без вчителя).

---

## 🚀 Ключові архітектурні особливості

### 1. Універсальність та автоматична типізація
- **Жодних захардкоджених стовпців**: типи ознак (числові, категоріальні, часові мітки/дати) визначаються автоматично на основі структури даних.
- Користувач самостійно обирає предиктори ($X$) та цільову змінну ($y$).
- Попередження та контроль високої кардинальності категорій (>50 унікальних значень).

### 2. Захист від витоку даних (Data Leakage Free)
- Усі кроки попередньої обробки (імпутація пропусків, масштабування `StandardScaler`/`RobustScaler`, кодування `OneHotEncoder(handle_unknown='ignore')`) реалізовано виключно через `sklearn.compose.ColumnTransformer` всередині `sklearn.pipeline.Pipeline`.
- Трансформери навчаються (`fit`) строго на тренувальній вибірці (`X_train`) і лише застосовуються (`transform`) до тесту (`X_test`).

### 3. Гнучкий поділ вибірки
- **Випадковий стратифікований поділ** для класифікації (зберігає співвідношення класів).
- **Хронологічний поділ («минуле → майбутнє» без перемішування/shuffle)** при виборі стовпця з датою (критично важливо для часових рядів та реєстрів).
- Фіксований генератор псевдовипадкових чисел `random_state=42` для повної відтворюваності.

### 4. Комплексний ML-інструментарій
- **Класифікація:** `LogisticRegression` та `RandomForestClassifier`. Врахування дисбалансу класів (`class_weight='balanced'`), метрики Accuracy, Macro Precision, Macro Recall, Macro F1, звіт `classification_report`, інтерактивна матриця невідповідностей (`confusion_matrix`).
- **Регресія:** `Ridge` (із регуляризацією $\alpha$) та `RandomForestRegressor`. Метрики $MAE$, $RMSE$, $R^2$, графіки розсіювання «Факт vs Прогноз» ($y = x$) та розподілу залишків (residuals).
- **Виявлення аномалій:** `IsolationForest` та `LocalOutlierFactor` із налаштуванням contamination rate. Топ-N таблиця підозрілих записів, **z-score пояснення** ключових факторів відхилення ($|z| = \frac{|x - \mu|}{\sigma}$), 2D PCA проекція простору ознак. Жорстке дотримання наукової методології (метрика accuracy не застосовується для задач без вчителя).

### 5. Інтерпретація та експорт
- Для кожного результату надаються методичні блоки **«💡 Як інтерпретувати результати»** та **«⚠️ Обмеження методу»** українською мовою.
- Завантаження збагачених датасетів із прогнозами та скорами аномалій у форматі CSV (UTF-8 із BOM для коректного відкриття в Microsoft Excel).
- Експорт серіалізованих моделей у формат `.joblib` для подальшого продакшн-використання.

## 🛠️ Швидкий старт

### 1. Клонування та створення віртуального середовища

```bash
# Перехід у робочу директорію проєкту
cd d:/ed/python

# Створення віртуального середовища
python -m venv .venv

# Активація віртуального середовища:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (CMD):
.venv\Scripts\activate.bat
# Linux / macOS:
source .venv/bin/activate
```

### 2. Встановлення залежностей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Запуск веб-застосунку

```bash
streamlit run app.py
```

Після запуску перейдіть у веб-браузері за адресою: **[http://localhost:8501](http://localhost:8501)**.

## 🧪 Запуск тестів (Pytest)

Проєкт містить повне тестове покриття, що перевіряє поведінку на чистих, зашумлених та невалідних даних:
- Пропуски у числових та категоріальних ознаках.
- Один або надто рідкісні класи (<2 зразків).
- Нечислова ціль у задачі регресії.
- Спроба витоку даних (цільова змінна серед ознак).
- Недостатній розмір вибірки (<30 рядків).
- Стовпці зі 100% пропусків (NaN).

Запуск усіх тестів:
```bash
pytest tests/ -v
```

## 📋 Вимоги до структури файлів користувача

- **Підтримувані формати**: `.csv`, `.tsv`, `.xlsx`, `.xls`.
- **Кодування тексту**: `utf-8` (стандартне) або `windows-1251` (поширене в офіційних українських реєстрах).
- **Роздільники CSV**: кома (`,`), крапка з комою (`;`), табуляція (`\t`), вертикальна риска (`|`) — підтримується автоматичне виявлення та ручний вибір.
- **Структура**: Перший рядок таблиці має містити заголовки стовпців.
- **Мінімальний обсяг**: Рекомендовано від 30 заповнених рядків для забезпечення статистичної стійкості оцінок.
